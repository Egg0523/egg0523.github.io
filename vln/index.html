Dual-System Vision-and-Language Navigation

A language-conditioned navigation stack for the AgiBot X2 humanoid, from simulation to hardware.

AgiBot · Motion Intelligence Group · 2026 · Simulation and hardware

Overview

A navigation stack that takes a natural-language instruction and produces motion, split across two systems running at different rates. A vision-language model reads the instruction and the current view and decides where to go; a faster trajectory network turns that decision into dense waypoints, so semantic reasoning never has to run at control rate.

The training data was built from scratch: 4,229 R2R/RxR trajectories across 60 Matterport3D scenes, with the 3-D paths projected onto egocentric views and depth-filtered for visibility, then segmented into 251,916 samples covering pixel-goal grounding, self-directed view adjustment and STOP supervision.

Method

  • Pixel-goal grounding — a LoRA-finetuned 7B vision-language model emits the farthest reachable waypoint currently in view as a pixel coordinate, rather than a text plan.
  • Self-directed view adjustment — when the goal falls outside the frame, the model turns or looks down on its own until it is visible.
  • Latent-query interface — the model is then frozen; learnable latent queries pull its hidden state out as the condition for the downstream network, so no gradient crosses back into the VLM.
  • Flow-matching trajectories — a flow-matching network generates 32 dense waypoints from that condition.
  • Asynchronous rates — the two run at 2 Hz and 30 Hz, so slow reasoning never blocks the control loop.

On hardware

The same stack now runs on the X2. The instruction goes in as free text; the model’s goal is projected into the body frame as a waypoint and handed to the local planner, which turns it into velocity commands under its own safety limits.

The instruction for this run is “Walk past the black box, turn right at the black chair, and stop in front of the white chair.” The first few seconds show the operator console.

The layer underneath — the one that turns a goal point into velocity commands the robot can actually execute — is on its own page.
